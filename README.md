# 👋 Nina Clark: Personal Portfolio

**🌐 Live: [ninaclark.dev](https://ninaclark.dev)**

My personal portfolio site, covering design, development and data work. It's a single static page with no build step and no framework.

## ✨ About the site

- 📄 **One file.** The whole site is a single `index.html`. The images are embedded in it, so there's nothing else to load or keep track of.
- 🌙 **Dark theme**, with a serif display font (Instrument Serif) paired with Inter for body text, JetBrains Mono for code-style text and Oswald for accents, all loaded from Google Fonts.
- 🚀 **Hosted on Netlify**, served at my own domain.

## 🛠️ Running it

There's nothing to install. Open `index.html` in a browser.

## 🔄 Updating it

Edit `index.html`, commit, and redeploy on Netlify.

## 🤖 How I built it (optional: keep only if true)

I built this with AI coding tools. I decided the design, the content and how it should feel, and I used the AI to help write and refine the code.
